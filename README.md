# IconForge Android

A native Android app for creating custom launcher icons and icon packs.

## Features
- Customizable blank icon templates, shapes, and colors
- Import and position custom images with size and rotation controls
- App package/component resolution helpers
- Android project with GitHub Actions debug APK build workflow

## Build
Push to `main` or run the **Build Android APK** workflow manually from the Actions tab. The generated debug APK is uploaded as the `IconForge-debug-apk` artifact.

> The APK must be built and tested by CI before it can be considered verified.
